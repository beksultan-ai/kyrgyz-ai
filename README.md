# KYRGYZ AI

**KYRGYZ AI** — Artificial Intelligence company from Kyrgyzstan for the world.

Official website of the company. Multilingual platform (Kyrgyz / Russian / English) with chat, voice, and image understanding.

## Brand

- **Name:** KYRGYZ AI  
- **Tagline:** Your World. Your AI.  
- **Positioning:** Sovereign AI company building global-scale intelligence from Kyrgyzstan.

## Features

- Multilingual AI chat (ky / ru / en)
- Speech-to-text & text-to-speech
- Image understanding
- User accounts & conversation history (Supabase)
- Professional corporate design ready for global presentation

## Stack

- Frontend: HTML, CSS, Vanilla JS
- Hosting: Cloudflare Workers / static assets
- Auth & DB: Supabase
- AI API: Cloudflare Workers (`kyrgyz-ai-server`)

## Deploy

```bash
# Cloudflare
npx wrangler deploy
```

Or publish the folder to GitHub Pages / any static host.
